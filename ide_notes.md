# IDE или CLI

## Что удобно в VS Code
1. Визуальный diff - сразу видно, что изменилось.
2. Разрешение merge-конфликтов через встроенный редактор.
3. Быстрый коммит и пуш через UI без запоминания команд.

## Что удобнее в терминале
- Сложные операции: `rebase -i`, `cherry-pick`, работа с несколькими удалёнными репозиториями в CLI нагляднее и быстрее.
